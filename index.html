Complaint Registration and Tracking System in Java

1. Aim

To design and implement a Complaint Registration and Tracking System in Java using Object Oriented Programming concepts, where customers can register complaints and track their progress, and an administrator can review and update the status of complaints.

2. Abstract

Organizations often lose or delay customer complaints when they are handled manually. This project provides a role-based Java application in which customers register, log in, and file complaints with a category, description and priority (LOW, MEDIUM, HIGH). Every complaint receives a unique ID and a filing date. Customers can track a complaint by its ID or view all of their own complaints. The administrator can view all complaints, update their status (REGISTERED, IN_PROGRESS, RESOLVED) with remarks, and generate a summary report.

The project applies classes and objects, encapsulation, inheritance, abstraction, polymorphism, enumerations, collections, and custom exception handling.

3. Problem Statement

Organizations receive many complaints from customers, and handling them manually leads to delays and lost records. The system provides an application in which every complaint is given a unique ID, stored with its category, priority and status, and can be tracked at any time until it is resolved.

4. Key Features

  • Customer registration and login (role based: Customer / Admin).
  • Filing a complaint with category, description and priority (LOW, MEDIUM, HIGH).
  • Auto-generated unique Complaint ID (starts at 1001) and filing date.
  • Tracking a complaint by ID and viewing all complaints of a customer.
  • Admin can view all complaints, update status (REGISTERED, IN_PROGRESS, RESOLVED) with remarks, and see a summary report.
  • Error handling for invalid IDs, invalid status/priority and invalid menu input.

5. Conclusion

The Complaint Registration and Tracking System was implemented successfully in Java. It demonstrates classes, encapsulation, inheritance, abstraction, interfaces, polymorphism, enums, collections, and custom exception handling in a practical enterprise application.
